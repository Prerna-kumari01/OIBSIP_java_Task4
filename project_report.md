ONLINE EXAMINATION SYSTEM

Project Report

1. Introduction

The Online Examination System is a Java-based desktop application developed using Java Swing and SQLite. It provides students with a graphical interface to log in, manage their profiles, take examinations, and view previously saved results.

2. Problem Statement

Managing examinations and maintaining student results manually can require considerable effort. This project demonstrates a computer-based approach to examination management, with timed tests and database-backed result storage.

3. Objectives

- To develop a simple desktop examination application.
- To provide student login and profile management.
- To conduct timed examinations.
- To support automatic submission when the examination timer expires.
- To save examination results in a database.
- To allow students to view previous results.

4. Technologies Used

- Java
- Java Swing
- SQLite
- JDBC
- Visual Studio Code
- Java Development Kit (JDK)

5. Project Implementation

The application was developed using Java Swing for its graphical user interface and SQLite for data storage. JDBC was used to connect the application to the database.

The main implementation activities included:

1. Setting up the Java development environment.
2. Adding the SQLite JDBC driver.
3. Creating the database helper class and required tables.
4. Implementing student login and profile management.
5. Developing the examination interface.
6. Implementing the examination timer and automatic submission.
7. Saving examination results and providing access to previous results.

6. Testing and Results

The implemented application features were tested to check their basic operation. Testing covered application access, profile management, examination functionality, timer-based submission, and result storage.

The project demonstrates how a desktop application can combine a graphical interface with database operations.

7. Outcome

The project provides a desktop-based examination application with student login, profile management, timed examinations, automatic submission, and previous-result viewing.

8. Limitations

The application is a desktop-based project. Its functionality is limited to the features implemented in the current version. Additional features, such as administrative examination management and online deployment, could be considered for future development.

9. Future Scope

Possible improvements include:

- Adding an administrator module for managing questions.
- Supporting more question types.
- Improving examination security.
- Generating detailed performance reports.
- Developing a web-based version.

10. Conclusion

The Online Examination System demonstrates the practical use of Java Swing, SQLite, and JDBC. Developing this project provided experience in desktop application development, database connectivity, profile management, timed examinations, and result handling.
